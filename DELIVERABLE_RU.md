# Stepik Agent — материалы для сдачи

## Репозиторий

https://github.com/pymlex/stepik-agent

```bash
git clone https://github.com/pymlex/stepik-agent
cd stepik-agent
```

## Запуск

1. Клонировать репозиторий и установить зависимости: `pip install -r requirements.txt`.
2. Скопировать `.env.example` в `.env` и указать `OPENAI_API_KEY` для Zveno API. Остальные ключи опциональны.
3. Проверка end-to-end: `python scripts/run_e2e.py` — в конце должно быть `E2E PASS`.
4. Чат Gradio: `python main.py` при `PYTHONPATH` равном корню репозитория.
5. Запись на курс: `stepik_config.json` из примера, в чате «запись на курс ID», затем «подтверждаю запись».

```powershell
git clone https://github.com/pymlex/stepik-agent
cd stepik-agent
pip install -r requirements.txt
$env:PYTHONPATH = (Get-Location)
copy .env.example .env
python scripts/run_e2e.py
python main.py
```

## Описание

Агент решает задачу подбора курсов на Stepik под сформулированную цель обучения: пользователь не просматривает вручную десятки карточек и не смешивает желаемую тему с жёсткими ограничениями в одном неструктурированном запросе.

Pipeline построен по этапам. Сначала принимается текстовая цель, затем отдельным блоком — язык, платность, рейтинг, нагрузка и другие поля только из ответов пользователя. LLM через Pydantic-модели генерирует несколько поисковых строк, Stepik API вызывается по каждой, выдачи объединяются и режутся детерминированными фильтрами. Оркестратор просматривает первую выдачу, уточняет запросы, повторяет поиск, проверяет актуальность тем через DuckDuckGo и ранжирует курсы с цитатами из полей карточки и списком отсечённых позиций.

LLM используется для генерации запросов, уточнения запросов после обзора выдачи, ранжирования с обоснованием, ответов на вопросы по курсам в follow-up. Обычная логика покрывает парсинг формы, фильтрацию по API и правилам, слияние результатов, логирование в SQLite, защиту от jailbreak, отображение этапов в Gradio и подтверждённую запись на курс через Playwright.

Ограничения: качество ранжирования зависит от полноты карточек Stepik и от внешнего поиска DDG. Пустая выдача не дополняется вымышленными курсами. Секреты хранятся только в `.env`, файл не коммитится. Запись на курс требует ручного входа в браузере и стабильной вёрстки Stepik.

Следующий шаг — довести запись на курс до устойчивого сценария: явное подтверждение в чате, устойчивые селекторы кнопок «Поступить на курс», корректное закрытие окна браузера без падения процесса.
