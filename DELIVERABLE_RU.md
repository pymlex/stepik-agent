# Stepik Agent — материалы для сдачи

## Репозиторий

https://github.com/pymlex/stepik-agent

**Описание на GitHub:** An automated agent for smart search of Stepik courses.

**Лицензия:** [GNU General Public License v3.0](https://www.gnu.org/licenses/gpl-3.0.html), файл `LICENSE` в корне репозитория.

```bash
git clone https://github.com/pymlex/stepik-agent
cd stepik-agent
pip install -r requirements.txt
```

Запуск из корня клона, переменная `PYTHONPATH` не требуется: пути подключает `bootstrap_path.py`.

## Запуск

| Действие | Windows | Linux / macOS |
| --- | --- | --- |
| Полный прогон для отчёта | `run_report.bat` | `python scripts/generate_report.py` |
| Проверка E2E | `run_e2e.bat` | `python scripts/run_e2e.py` |
| Чат Gradio | `run_gradio.bat` | `python main.py` |

Перед первым запуском: `copy .env.example .env` и заполнить `OPENAI_API_KEY` для Zveno API. Лог последнего прогона: `artifacts/report_run.txt`.

## Описание

Агент подбирает курсы на Stepik под сформулированную цель обучения. Пользователь задаёт цель свободным текстом, затем отвечает на фиксированный блок из пяти полей: язык, платность, порог `learners_count`, нагрузка, рейтинг. Ответ «пропустить» оставляет критерий нейтральным при взвешивании.

Pipeline по этапам: цель → форма → генерация нескольких поисковых строк через Pydantic и LLM → вызовы Stepik API по каждой строке → объединение карточек → обзор первичной выдачи → уточнение запросов → повторный поиск → проверка актуальности тем через DuckDuckGo → ранжирование. Параметр `is_paid` в запрос к Stepik API не передаётся, платность учитывается только при локальном подсчёте критерия `price_fit` в `weighted_scorer.py`. Жёсткое отсечение по одному полю не применяется: несовпадение даёт пониженный балл по критерию, а не пустую выдачу.

Восемь критериев с весами по умолчанию: соответствие цели, актуальность 2026, язык, цена, нагрузка, рейтинг, число учеников, популярность. LLM дополняет краткое резюме и развёрнутое обоснование поверх уже посчитанных баллов. Обычная логика покрывает парсинг формы, слияние результатов поиска, SQLite для предпочтений и `search_log`, jailbreak-guard, Markdown в Gradio, MCP-сервер и запись на курс через Playwright после подтверждения в чате.

Ограничения: качество ранжирования зависит от полноты карточек Stepik и от ответов DuckDuckGo. Пустая выдача не дополняется вымышленными курсами. Секреты только в `.env`, файл в git не попадает. Запись на курс требует ручного входа в браузере и устойчивой вёрстки Stepik.
