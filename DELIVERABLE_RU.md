## Запуск

1. Перейти в каталог проекта и задать `PYTHONPATH` на корень репозитория.
2. Положить ключ API в `zveno.txt` в корне или в `.env` как `OPENAI_API_KEY=...`. Базовый URL и модель по умолчанию: `https://api.zveno.ai/v1`, `openai/gpt-oss-120b`.
3. Запустить чат: `python main.py`
4. Демо без Gradio: `python scripts/run_demo.py`
5. Запись на курс после подтверждения в чате: скопировать `stepik_config.json.example` в `stepik_config.json`, затем `python scripts/enroll_course.py "https://stepik.org/course/67/promo"`

## Описание

Агент решает задачу подбора курсов на Stepik под сформулированную цель обучения: пользователь не просматривает вручную десятки карточек и не смешивает желаемую тему с жёсткими ограничениями в одном неструктурированном запросе.

Pipeline построен по этапам. Сначала принимается текстовая цель, затем отдельным блоком — язык, платность, рейтинг, нагрузка и другие поля только из ответов пользователя. LLM через Pydantic-модели генерирует несколько поисковых строк, Stepik API вызывается по каждой, выдачи объединяются и режутся детерминированными фильтрами. Оркестратор просматривает первую выдачу, уточняет запросы, повторяет поиск, проверяет актуальность тем через DuckDuckGo и ранжирует курсы с цитатами из полей карточки и списком отсечённых позиций.

LLM используется для генерации запросов, уточнения запросов после обзора выдачи, ранжирования с обоснованием, ответов на вопросы по курсам в follow-up и при необходимости для LLM-as-judge в тестах. Обычная логика покрывает парсинг формы, фильтрацию по API и правилам, слияние результатов, логирование в SQLite, защиту от jailbreak, отображение этапов в Gradio и подтверждённую запись на курс через Playwright.

Ограничения: качество ранжирования зависит от полноты карточек Stepik и от внешнего поиска DDG. Пустая выдача не дополняется вымышленными курсами. Токены и пароли не должны попадать в git. Запись на курс требует ручного входа в браузере и стабильной вёрстки Stepik.

Следующий шаг — довести запись на курс до устойчивого сценария: явное подтверждение в чате, устойчивые селекторы кнопок «Поступить на курс», корректное закрытие окна браузера без падения процесса, опционально привязка к `STEPIK_API_TOKEN` для ускоренного API.
